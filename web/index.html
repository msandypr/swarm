Browser Integration Setup

Pasang ekstensi Swarm ke Microsoft Edge, Chrome, atau Brave dalam 2 langkah mudah:

1
Buka Halaman Ekstensi & Aktifkan Developer Mode

Ketik edge://extensions di browser, lalu nyalakan toggle Mode Pengembang (Developer mode).

2
Klik Load Unpacked

Klik tombol Muat yang belum dibongkar (Load unpacked), lalu pilih folder extension Swarm yang terbuka.
